The HR Employee Analytics project is a comprehensive data analysis initiative designed to uncover workforce trends and understand the primary drivers of employee attrition. Employee turnover is a significant cost for organizations, and identifying the root causes is crucial for improving retention, engagement, and overall workplace satisfaction.

This project explores a complex human resources dataset to track KPIs and visualize patterns across different departments, job roles, and demographics. By transforming raw HR data into interactive dashboards, this project provides actionable insights that can empower HR leadership to make data-driven decisions.

Key Features
KPI Tracking: High-level metrics tracking total headcount, current attrition rate, average employee age, and average tenure.

Demographic Breakdown: Visualizations detailing attrition across gender, age groups, and marital status to identify vulnerable employee segments.

Departmental Analysis: A deep dive into specific departments (e.g., Sales, R&D, HR) and job roles to pinpoint areas with the highest turnover rates.

Satisfaction & Income Correlation: Analysis of how job involvement, performance ratings, and monthly income influence an employee's decision to leave the company.

Tech Stack Used
Excel: Utilized for initial data cleaning, formatting, and handling missing values to ensure data integrity.

SQL: Used to query the dataset, perform complex aggregations, and structure the data for analytical reporting.

Power BI: Deployed to build dynamic, interactive dashboards and visual reports that allow users to filter and explore the data seamlessly.

Business Value
By analyzing the workforce data, this project highlights specific retention strategies. It helps identify which employee groups are most at risk of leaving, whether salary adjustments are needed in specific departments, and how promotion frequency impacts long-term loyalty. Ultimately, it serves as a functional tool for optimizing human capital management.
